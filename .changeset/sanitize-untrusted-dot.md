Check DOT before rendering it: `sanitize`, on by default in the adapter

- New `sanitize(dot, options?)` in `@ts-graphviz/ast` (and `ts-graphviz/ast`): parses the source with the parser limits, checks it on the AST and returns the DOT printed from the checked AST, so Graphviz reads exactly what was checked. It rejects what makes Graphviz read a file (`image`, `shapefile`, `imagepath`, `fontpath`, `stylesheet`, xdot drawing programs, `<IMG>` / `SRC`), unsafe links (URL attributes and `HREF` other than relative, `http`, `https` and `mailto`, or with whitespace, control characters, quotes, angle brackets or backslash escapes), and values Graphviz writes raw into PostScript, image maps, `plain`, JSON or XML output (font names other than plain names, unknown `style` values, non-name shapes, colors outside the color syntax, substitution escapes (`\N`, `\L`, …) that could assemble a character reference, control characters, line breaks in names, ports and `comment`, undefined named references outside labels and tooltips). Every check runs at every level of character-reference decoding. Without `options.format` it applies the rules of every checked format at once; with one, only that format's rules (e.g. single-word font names and styles only for PostScript and `plain`), and it rejects `ismap` and unchecked formats. `policy: 'strict'` additionally allows only the attributes ts-graphviz knows (exact names), plain values for attributes without a grammar of their own, and the HTML-like label tags and attributes Graphviz defines. Rejections are a `DOMException` named `SecurityError` with code `TSG_ERR_UNSAFE_DOT`.
- **Breaking:** `toBlob` of `@ts-graphviz/adapter` (and `ts-graphviz/adapter`, for DOT and models) run `sanitize` by default and render its output. The adapter passes its `format`, so `ismap` and formats whose output has not been checked (e.g. `vml`, `fig`) are refused unless `sanitize: false`. Unsafe DOT rejects before the command starts, and DOT that does not parse rejects with `DotSyntaxError` rather than a `CommandExecutionError`. The `attributes` option (`-G` / `-N` / `-E`) is checked by the same rules, on the exact text of each argument: a key or value containing a line break, or with a backslash before a quote or at its end, is rejected with the same `SecurityError`. Pass `sanitize: false` for DOT you trust (e.g. your own images), or parser limits as `sanitize: { … }`. `@ts-graphviz/adapter` now depends on `@ts-graphviz/ast`.
